# ISO — BIM and built-asset information reference pointers

Citation-only directory, checked 2026-11-06 (Asia/Dubai). Own-word subject
locators and document identifiers only; no licensed clauses, workflow rules,
technical values or schema text. The source for all published identifiers and
scope divisions below is ISO's construction-information committee catalogue [I1].

This directory adds standard-level routing to the general
[WBDG BIM note](wbdg_bim.md); it does not repeat its execution-plan or LOD guidance.

## ISO 19650 — information management across asset stages

| Citation | Coverage pointer | Where it sits |
|---|---|---|
| ISO 19650-1:2018 | Shared information-management concepts for BIM work | Entry to the series |
| ISO 19650-2:2018 | Information management while an asset is being delivered | Delivery-stage reference |
| ISO 19650-3:2020 | Information management while an asset is in use | Operations-stage reference |
| ISO 19650-4:2022 | Managed exchange of information | Exchange interface across activities |
| ISO 19650-5:2020 | Information management with security sensitivity in view | Security overlay, not a disclosure permission |
| ISO 19650-6:2025 | Health/safety-related information in BIM-enabled work | Safety-information interface |

The catalogue also lists ISO/DIS 19650-1, -2 and -3 as revisions in development.
Their proposed scope division differs from the published series. A draft is not
silently substituted for a published part, and the older delivery/operations
labels above must not be assigned to a draft with a changed scope [I1].

## Related information standards — distinct roles

| Citation | Coverage pointer | Where it sits |
|---|---|---|
| ISO 7817-1:2024 | Concepts for expressing the level of information needed | Information-requirement definition, not a universal numeric LOD ladder |
| ISO 12006-2:2015 | Organization of construction classifications | Classification framework, not a ready-made national classification table |
| ISO 12006-3:2022 | Object-based organization of construction information | Information/dictionary framework |
| ISO 12911:2023 | Framework for specifying BIM implementation | Implementation-specification reference |
| ISO 16739-1:2024 | IFC representation for exchanging construction/facility data | Exchange schema, not the information-management process itself |
| ISO 21597-1:2020 | Container for linked delivery documents | Packaging/exchange reference |
| ISO 21597-2:2020 | Relationships linking items in that container | Companion to the container part |
| ISO 23386:2020 | Description and maintenance of properties across connected dictionaries | Property-definition reference |
| ISO 23387:2025 | Templates describing asset-related object data | Object-template reference |
| ISO 29481-1:2025 | Method and structure of information-delivery manuals | Exchange-requirement documentation |
| ISO 29481-2:2025 | Interaction framework within that manual approach | Participant/interaction reference |
| ISO 29481-3:2022 | Schema associated with information-delivery manuals | Machine-readable representation reference |

The listed IFC, object-template and information-delivery-manual editions reflect
the published catalogue records, rather than assuming their older editions are
still current. Draft ISO 7817 companion parts are not listed as published [I1].

## Application boundary

These ISO identifiers are not automatically BS EN ISO adoptions and do not imply
that a jurisdiction or contract has adopted them. Required national adoption,
applicable edition/amendments and exchange specification: **confirm against the
official code** or standard and the applicable information requirements. No file
naming convention, approval state, security classification or model-detail value
is prescribed by this directory.
