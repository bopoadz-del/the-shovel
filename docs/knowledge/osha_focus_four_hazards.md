# Construction Safety — Leading Hazards & Corrective Controls (OSHA Focus Four)

Reference note on the leading causes of construction fatalities and the controls
that prevent them. Source: OSHA "Focus Four" / "Fatal Four" construction hazards.
This is a lessons-learned / indicative layer (leading causes + standard corrective
controls), NOT a regulation and NOT a set of exact statistics — the binding
requirements live in the OSHA standards notes (fall protection, excavations,
scaffolds, stairways/ladders, crane clearance) and the project HSE plan. The
hazard patterns and controls are universal; US-reference framing, but they apply
on any site. Pairs with those standards notes: this note is "what goes wrong and
the corrective action"; those notes are "the numeric requirement".

## The Focus Four hazards and their corrective controls

| Hazard | What it is | Leading causes | Primary corrective controls |
|---|---|---|---|
| Falls (the leading cause of construction deaths) | Fall to a lower level | Unprotected edges and floor/roof openings, ladders, scaffolds, roof work | Guardrails, personal fall arrest (PFAS), hole covers; training; pre-use inspection — see the fall-protection note |
| Struck-by | Struck by a moving/falling/flying object or vehicle | Mobile plant and vehicles, falling or swinging loads, crane operations, flying fragments | Exclusion zones, spotters/banksman, secured/rigged loads, hi-vis PPE, traffic management — see the crane clearance note |
| Caught-in / between | Crushed or trapped between objects or in a collapse | Unprotected excavations/trenches, unguarded machinery, pinch points | Protective systems / sloping / shoring, machine guarding, lockout/tagout (LOTO) — see the excavations note |
| Electrocution | Contact with live electrical power | Overhead power lines, unguarded wiring, missing lockout, unqualified work | Line clearances, GFCI/RCD protection, lockout/tagout, qualified persons only — see the crane clearance note |

Source: OSHA Focus Four construction hazards (leading-cause categories). Exact
current shares should be confirmed against the latest OSHA / BLS data.

## The corrective-action pattern

For each hazard the prevention hierarchy is the same, best first:
1. Eliminate / substitute the hazard (design it out, relocate the line, avoid the lift).
2. Engineering controls (guardrails, shoring, machine guards, GFCI).
3. Administrative controls (exclusion zones, permits, spotters, training, inspection).
4. PPE (harness, hi-vis, insulating equipment) as the last layer, never the first.

## How to use

- Use this to explain the leading hazards, their common causes, and the corrective
  action that prevents each — the lessons-learned layer.
- The numeric requirements live in the OSHA standards notes and the project HSE
  plan; this note points to them, it does not replace them.
- Do not quote a fatality percentage as fact — say "a leading cause per OSHA
  Focus Four" and, if a figure is needed, confirm it against current OSHA/BLS data.
