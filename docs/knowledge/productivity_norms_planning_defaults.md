# Trade Productivity Norms — Published Planning Ranges

Daily output ranges per tradesman for common building trades, for use as the
CITED-REFERENCE tier of the variable-sourcing order in the interior finishes
process (see the Interior Finishes Process Contract): project documents
first, then project facts, then these published references, then ask the
operator. These are PLANNING ranges from published estimating references —
never silent defaults: an estimate that uses one must cite this table and
state the value chosen, and a contractor's own measured outputs always
override them.

|---|---|---|---|---|

| Emulsion paint, 2 coats on plaster | m² | 20 | 25 | 35 |
| Gypsum board ceiling on grid | m² | 12 | 15 | 20 |

| Rebar cut, bend and fix | kg | 250 | 350 | 500 |
| Structural concrete place + finish (gang of 6) | m³ | 25 | 35 | 50 |

Sources: consolidated from published estimating references in general use in
the GCC (institutional estimating handbooks and the published composite-rate
build-ups behind the Turner & Townsend KSAMI and AECOM Middle East
handbooks). Ranges deliberately wide: crowding, height, access, weather and
repetition move real outputs across the whole span.

## Rules of use

1. A quantity or cost derived from a norm here must state the norm used and
   cite this table; ranges are chosen mid unless the basis says otherwise.
2. Per-project or per-floor measured values ALWAYS override these ranges —
   store them as project facts and they win the sourcing order.
3. These norms never enter code or calculators as defaults; calculators
   require the value as an input (the process-contract rule).
