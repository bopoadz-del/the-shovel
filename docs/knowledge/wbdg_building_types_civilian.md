# Building Types — Civilian Design Considerations (WBDG)

Reference guidance on the design drivers of common civilian building types.
Source: WBDG Building Types (civilian subset; military/federal-specific types are
excluded). Best-practice guidance, not a regulation — the project brief and local
code govern any specific building. International practice, applies to KSA. Each
type below is a short summary of what most shapes its design; use it to frame a
brief, not as a specification.

## Civilian building types — primary design drivers

| Type | What most drives the design |
|---|---|
| Office | Flexibility of floorplate, daylight and views, indoor environmental quality, efficient core, adaptability to fit-out changes |
| Parking | Structural efficiency (long spans, flat plates), circulation and ramp geometry, ventilation, lighting, security/wayfinding |
| Warehouse / distribution | Clear height, column grid, floor flatness/loading, dock and turning geometry, fire protection (high-pile storage), thermal envelope if conditioned |
| Health care | Infection control, rigorous HVAC (pressure/filtration), resilience and redundancy of services, strict adjacencies, 24/7 operation |
| Educational | Acoustics, daylight, flexible/reconfigurable spaces, safety and security, durability against heavy use |
| Libraries | Floor loading for stacks, environmental control for collections, daylight without glare, acoustics, flexible technology |
| Research facilities / laboratories | Ventilation and containment, utility/services flexibility, safety (fume/chemical), vibration control, modular lab planning |

Source: WBDG Building Types (civilian).

## How to use

- Use this to explain what dominates a given building type's design and to sanity-
  check a brief (e.g. a lab brief that omits ventilation/containment, or a
  warehouse brief that omits clear height).
- These are general drivers; the project brief, programme, and local code are
  authoritative for a specific building.
- Military/federal-specific types (armories, ammunition magazines, barracks,
  waterfront, land ports of entry) are deliberately excluded as out of scope.
