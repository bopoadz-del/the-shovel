# Stairways & Ladders — Site Safety Criteria (OSHA 29 CFR 1926 Subpart X)

REAL, sourced stairway and ladder thresholds for construction sites. Source:
OSHA 29 CFR 1926.1052 (stairways) and 1926.1053 (ladders), Subpart X, US federal
regulation, public domain. US-reference standard: in Saudi Arabia site HSE is
governed by Saudi labour law (MHRSD) and the project HSE plan, not OSHA, but
Saudi practice broadly aligns. Values are metric-led (SI) with the original
US-customary figure in parentheses.

## Ladders

| Parameter | Value (SI) | Original (US) |
|---|---|---|
| Extension above the upper landing surface | 0.9 m | 3 ft |
| Set-up pitch (base distance ≈ ¼ of working length) | 4 : 1 (75° approx) | 4 : 1 |
| Rung / step spacing | 25–36 cm | 10–14 in |
| Minimum clear width between side rails (portable) | 29 cm | 11½ in |
| Minimum perpendicular clearance behind rungs | 18 cm | 7 in |
| Load capacity (safety factor) | 4× intended load | 4× intended load |

Source: OSHA 29 CFR 1926.1053(a)–(b).

## Stairways

| Parameter | Value (SI) | Original (US) |
|---|---|---|
| Stairrails/handrails required at | 4+ risers or rise > 76 cm | 4+ risers or > 30 in |
| Handrail height above tread | 76–94 cm | 30–37 in |
| Stairrail top-edge height (systems after 15 Mar 1991) | ≥ 91.5 cm | ≥ 36 in |
| Maximum vertical rise between landings | 3.7 m | 12 ft |
| Riser height / tread depth uniformity tolerance | ≤ 0.6 cm | ≤ ¼ in |
| Permitted stairway angle from horizontal | 30°–50° | 30°–50° |

Source: OSHA 29 CFR 1926.1052(a)–(c).

## KSA applicability

OSHA 1926 is a US-reference standard, not the governing authority in Saudi
Arabia (site HSE is under Saudi labour law / MHRSD and the project HSE plan).
Saudi practice broadly aligns on ladder extension above landing, the 4:1 set-up
pitch, and stairrail heights. Where a value is enforced on site, confirm it
against the project HSE plan.

## How to use

- Quote the SI value for site use; cite the US original and the regulation
  number so the basis is traceable.
- The project HSE plan and the equipment manufacturer's data take precedence
  over these reference figures.
- State that this is a US-reference figure, not the governing authority for a
  Saudi project.
