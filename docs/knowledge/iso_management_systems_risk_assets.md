# ISO — management systems, risk, assets and project references

Citation-only directory, checked 2026-11-06 (Asia/Dubai). Original subject
pointers, not reproduced clauses, audit criteria or operating procedures.
Publication years and amendment identifiers are citation metadata, not technical
values. Organizational standards do not replace the building-code design layer.

## Organizational systems and supporting guidance

| Citation | Coverage pointer | Where it sits / source |
|---|---|---|
| ISO 9000:2026 | Quality-management vocabulary and underlying concepts | Companion context for ISO 9001 [Q1] |
| ISO 9001:2026 | An organization's quality-management system | System-level assurance rather than product design approval [Q1] |
| ISO 10005:2018 | Guidance for quality plans | Planning support alongside the quality system [Q2] |
| ISO 10006:2017 | Quality-management guidance in project settings | Project-quality interface [Q2] |
| ISO 19011:2026 | Guidance for management-system auditing | Audit practice support; not a separate certification target [Q3] |
| ISO 14001:2026 | An organization's environmental-management system | Organizational environmental control, distinct from product LCA [E1] |
| ISO 45001:2018; Amd 1:2024 | An organization's occupational health/safety system | Safety-management layer, not trade-specific construction safety limits [H1] |
| ISO 31000:2018 | General risk-management guidance | Cross-cutting governance reference; not a certifiable system standard [R1] |
| ISO 50001:2018; Amd 1:2024 | An organization's energy-management system | Energy-performance management, not a building-envelope design code [N1] |
| ISO 55000:2024 | Asset-management concepts and vocabulary | Context for the asset-management family [A1] |
| ISO 55001:2024 | An organization's asset-management system | Asset-governance system rather than an inspection interval schedule [A2] |
| ISO 41001:2018; Amd 1:2024 | Management of facility-service delivery | Facility-management system rather than structural assessment rules [F1] |

The official records identify ISO 9001, ISO 14001 and ISO 19011 publications in
2026; older editions are not presented here as the current publications. ISO
45001 and ISO 41001 still have published editions alongside developing DIS
revisions, which are not treated as replacements already in force [Q1, E1, Q3,
H1, F1]. This directory does not assign certification-transition deadlines.

ISO's management-system list distinguishes requirements documents from supporting
guidance [A1]. A system certificate and approval of a building or product answer
different questions; the scope pointer here does not establish either approval.

## Application boundary

Applicable contract/national adoption, required edition, amendment set,
certification scope and any transition arrangement: **confirm against the
official code** or standard and the relevant authority or certification body.
No audit frequency, scoring system, target, certification deadline or compliance
claim is supplied. For product/building environmental assessment, see the
[separate sustainability directory](iso_building_sustainability_service_life.md).
