# Building Commissioning — Process, Documents & Roles (WBDG)

Reference note on the building commissioning (Cx) process. Source: WBDG Building
Commissioning, framed on ASHRAE Standard 202-2018 and ASHRAE Guideline 0 (the
internationally used commissioning framework). Commissioning is a quality-assurance
process, not a country-specific regulation, so it applies directly to KSA projects;
the project's own Commissioning Plan and contract requirements govern the specific
scope. This note grounds the platform's commissioning checklist and complements the
document engine's OPR/BOD extraction — it is reference knowledge, not a new process.

## The commissioning process phases

| Phase | What happens | Key output |
|---|---|---|
| 1. Pre-design / Planning | Commissioning Provider (CxP) engaged; owner's needs captured | Owner's Project Requirements (OPR); initial Cx Plan |
| 2. Design | CxP reviews design against the OPR; design team documents its response | Basis of Design (BOD); Cx specifications; updated Cx Plan |
| 3. Construction | Submittal review; installation verification; functional performance testing (FPT) | Issues/deficiency log; FPT results |
| 4. Occupancy & Operations | O&M training; systems manual; seasonal / off-season testing; final report | Systems Manual; final commissioning report |

Source: WBDG Building Commissioning — The Process.

## Key commissioning documents

| Document | Purpose |
|---|---|
| OPR — Owner's Project Requirements | The owner's functional and performance needs; the benchmark everything is verified against |
| BOD — Basis of Design | The design team's documented response to the OPR |
| Commissioning (Cx) Plan | Roles, scope, process, and schedule for the Cx effort |
| Systems Manual | Handover package: OPR, BOD, as-builts, submittals, O&M manuals, test/verification reports, issue-resolution logs |

Source: WBDG Commissioning Documents; ASHRAE Standard 202 / Guideline 1.4-2019.

## Types of commissioning

| Type | When it applies |
|---|---|
| New construction Cx | New building or major renovation; starts at pre-design |
| Retro-commissioning (RCx) | Existing building that was never commissioned |
| Re-commissioning | Building that was previously commissioned |
| Ongoing / Continuous commissioning (OCx) | Continuous verification after occupancy |

Source: WBDG Building Commissioning.

## Roles

- Commissioning Provider (CxP) — leads the process; independent verification against the OPR. (Older term: Commissioning Authority / CxA.)
- Owner — sets the OPR, accepts the systems manual at handover.
- Design team — produces the BOD; resolves design-review issues.
- Contractor — installs, supports functional testing, closes deficiencies.
- Facility manager / O&M — receives training and the systems manual.

## How to use

- Use this to explain the Cx process, the document chain (OPR → BOD → Cx Plan →
  Systems Manual), the phases, and the roles.
- The project's Commissioning Plan and contract commissioning specification are
  authoritative for scope on any specific project — this is the general framework.
- Commissioning outcomes feed O&M handover; the Systems Manual is the bridge from
  construction to operations (see the O&M and BIM/COBie reference notes).
