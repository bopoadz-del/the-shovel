# Building Information Modeling (BIM) — Execution, LOD & Interoperability (WBDG)

Reference guidance on BIM in construction delivery. Source: WBDG Building
Information Modeling. Best-practice guidance and open-standard references, not a
regulation — the project's BIM Execution Plan and the client's BIM standard govern.
International practice (ISO 19650), applies to KSA projects. This note complements
the platform's existing BIM extraction/analysis capability — it is reference
knowledge, not new logic.

## What BIM is

BIM is a shared digital representation of a facility, built on open standards for
interoperability, used as a reliable basis for decisions across design,
construction, and operation.

Source: WBDG Building Information Modeling.

## BIM Execution Plan (BxP / PxP)

The project team develops a BIM Execution Plan that defines, for the project:
the BIM Uses (what the model is used for in each phase), the tools, and how BIM
data is managed and interoperates — storage, sharing, viewing, quality control,
and updating — across all team members.

Source: WBDG BIM — Project Execution Plan.

## Level of Development (LOD)

The reliability of a model element at a given stage. The LOD for each element is
set in the BIM Execution Plan (BIMForum LOD Specification).

| LOD | Element reliability |
|---|---|
| LOD 100 | Conceptual — symbolic; area/volume/orientation only |
| LOD 200 | Approximate geometry — generic placeholder, approximate size/shape/location |
| LOD 300 | Precise geometry — accurate size/shape/location; suitable for documentation |
| LOD 350 | Adds interfaces/connections between elements; for multi-trade coordination |
| LOD 400 | Fabrication and assembly detail |
| LOD 500 | Field-verified as-built; suitable for operations |

Source: BIMForum Level of Development (LOD) Specification (via WBDG).

## Interoperability

- Models should exchange through open standards. The Industry Foundation Classes
  (IFC) format (IFC 2x3 or newer) is the vendor-neutral exchange standard.
- ISO 19650 is the international standard for managing information over the asset
  life cycle using BIM.

Source: WBDG BIM — interoperability; IFC / ISO 19650.

## BIM to operations (COBie)

COBie (Construction-Operations Building Information Exchange) carries the asset
data captured in the model — equipment, spaces, spares, warranties — into facility
management at handover, so the FM/O&M system is populated from project data rather
than re-keyed. See the O&M reference note.

Source: WBDG — COBie.

## How to use

- Use this to explain BIM Uses, the Execution Plan, LOD reliability levels, IFC/

- The project's BIM Execution Plan and the client's BIM standard are authoritative
