# EMBEDDER_DECISION.md

Embedder selection benchmark for the Phase-1 RAG rebuild.
Generated by `scripts/benchmark_embedders.py`.

## Method

- **Recall subset**: seeded sample from `data/learning/training_scenarios_drive_archive_v2.jsonl`. Each row's ground-truth chunk is indexed under its doc_id/chunk_index, then the question is queried at the same embedder dimension.
- **Recall metric**: doc/chunk recall@5.
- **Fresh-upload wins**: the 12 single-chunk project-specific notes from `scripts/rag_fresh_upload_eval.py`. PASS = fresh doc is top-1 (top-3 tracked).
- **Fresh metric**: top-1 / top-3 fresh wins out of 12.
- Each candidate runs in its own throwaway namespace on the fixed namespace-aware vector store; the legacy `chunks` table is untouched.
- **Query-instruction prefix**: production retrieval (`retriever.py`) and this
  benchmark both apply `Embedder.query_instruction` to queries. For BGE models
  this is the standard `"Represent this sentence for searching relevant passages: "`
  prefix; for MiniLM/potion no prefix is applied. On this 20-question subset the
  prefix did not change BGE's scores; it is kept for consistency with the model
  card and so benchmark and prod remain matched.

## Results

| Model | Dim | Load (s) | Index (s) | doc@5 | chunk@5 | fresh top-1 | fresh top-3 |
|-------|-----|----------|-----------|--------|----------|-------------|-------------|
| minishlab/potion-base-8M | 256 | 18.6 | 0.2 | 0.95 | 0.55 | 12/12 | 12/12 |
| sentence-transformers/all-MiniLM-L6-v2 | 384 | 7.4 | 1.2 | 0.90 | 0.70 | 12/12 | 12/12 |
| BAAI/bge-small-en-v1.5 | 384 | 7.3 | 2.1 | 0.95 | 0.65 | 12/12 | 12/12 |

## What the table proves

The same `potion-base-8M` model that produced ~31% recall and 3/12 fresh-upload
wins in production now scores 0.95 doc recall and 12/12 fresh-upload wins on the
fixed code. The embedder was not the binding constraint — the dimension /
normalization corruption in the old vector store was. This benchmark primarily
validates that the rebuild code is free of that contamination bug class.

Because the sample is small (20 questions), the scores are ceiling-limited:
each question is worth 5%, so the 0.95 vs 0.90 doc@5 gap is one question. The
real embedder verdict is Phase 2's 100-question battery at full corpus scale.

## Decision

**Approved: `BAAI/bge-small-en-v1.5`** as the Phase-1 rebuild embedder.

**Riders:**
1. Query-instruction handling: production and benchmark apply the BGE retrieval
   prefix consistently (`Embedder.query_instruction`). Documented above; no
   score change observed on the subset, but the path is model-card-aligned.
2. Runner-up: `sentence-transformers/all-MiniLM-L6-v2`. If RAG_AUDIT_V4's
   full-scale numbers disappoint (doc@5 < 50% or chunk-level materially weak),
   the fallback is a MiniLM namespace — the namespace machinery makes that a
   re-embed, not a redesign.
3. The 20-question benchmark is acknowledged as ceiling-limited; the definitive
   embedder verdict is Phase 2's 100-question recall battery on the rebuilt
   corpus.
